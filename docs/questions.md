## Important: Question Q6

Q6 is intentionally outside the current OWASPShield dataset.

Our dataset currently contains only:
- Authentication Cheat Sheet
- Password Storage Cheat Sheet
- SQL Injection Prevention Cheat Sheet

It does not contain AWS CloudTrail or cloud audit-log information. Therefore, the current dataset cannot provide a reliable answer to Q6.
